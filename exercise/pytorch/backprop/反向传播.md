# Assignment 2：两层神经网络的前向传播与反向传播推导

> 基于 Iris 数据集、NumPy 实现的两层全连接神经网络。第一层为 10 个 ReLU 神经元，第二层输出 3 类 Softmax 概率。目标是理解并手动实现 `compute_neural_net_loss()` 中的前向计算、交叉熵与 L2 正则化，以及利用链式法则的反向传播。

## 1. 网络结构与符号

网络结构：**4 → 10 → 3**。

- 输入层：每个 Iris 样本有 4 个特征。
- 隐藏层：10 个神经元，使用 ReLU。
- 输出层：3 个类别，使用 Softmax。
- 优化方法：mini-batch SGD。

设批量大小为 $N$，类别数为 $C=3$，隐藏层宽度为 $H=10$：

| 符号 | 代码变量 | 形状 | 含义 |
|---|---|---|---|
| $X$ | `X` | $(N,4)$ | 批量输入 |
| $W_1$ | `W1` | $(4,10)$ | 第一层权重 |
| $b_1$ | `b1` | $(10,)$ | 第一层偏置 |
| $Z_1$ | `z1` | $(N,10)$ | 第一层线性输出 |
| $H_1$ | `h1` | $(N,10)$ | ReLU 后隐藏层输出 |
| $W_2$ | `W2` | $(10,3)$ | 第二层权重 |
| $b_2$ | `b2` | $(3,)$ | 第二层偏置 |
| $Z_2$ | `z2` | $(N,3)$ | 分类分数（logits） |
| $P$ | `probs` | $(N,3)$ | Softmax 概率 |
| $y$ | `y` | $(N,)$ | 类别整数标签（0、1、2） |
| $Y$ | 概念上的 one-hot | $(N,3)$ | 真实类别独热矩阵 |
| $L$ | `loss` | 标量 | 交叉熵加 L2 正则化 |

**形状原则**：每个参数的梯度必须与参数本身具有相同形状，即 `dW1.shape == W1.shape` 等。

## 2. 前向传播（Forward Propagation）

### 2.1 第一层：线性变换

$$
\boxed{Z_1=XW_1+b_1}
$$

单个样本中，第 $j$ 个隐藏神经元的线性结果为：

$$
z_{1,j}=\sum_{k=1}^{4}x_kw_{1,kj}+b_{1,j}
$$

批量矩阵相乘的形状：

$$
(N,4)(4,10)=(N,10)
$$

`b1` 的形状为 `(10,)`，NumPy 会将它广播到每个样本的行上。

```python
z1 = np.dot(X, W1) + b1
```

`np.dot(A, B)` 在这里（两个二维数组）进行矩阵乘法；`A @ B` 等价；`A * B` 表示逐元素乘法，不能替代这里的 `np.dot`。

### 2.2 ReLU 激活

$$
\boxed{H_1=\operatorname{ReLU}(Z_1)=\max(0,Z_1)}
$$

逐元素定义：

$$
\operatorname{ReLU}(z)=
\begin{cases}
z,&z>0\\
0,&z\le0
\end{cases}
$$

例如 `[-2, 0.5, 3, -1] → [0, 0.5, 3, 0]`。ReLU **引入非线性**，而且不改变数组形状。

```python
h1 = np.maximum(0, z1)
```

如果多个隐藏层只进行线性/仿射变换而没有非线性激活，整体依旧可以合并为一个仿射变换。

### 2.3 第二层：线性变换

$$
\boxed{Z_2=H_1W_2+b_2}
$$

形状：

$$
(N,10)(10,3)=(N,3)
$$

每行三个数是 **logits**，可以为负，也没有必须加和为 1 的限制。

```python
z2 = np.dot(h1, W2) + b2
```

### 2.4 Softmax：从 logits 到概率

单个样本的第 $j$ 类概率：

$$
\boxed{p_j=\frac{e^{z_j}}{\sum_{k=0}^{C-1}e^{z_k}}}
$$

性质：$0<p_j<1$，且 $\sum_jp_j=1$。例如 logits `[2,1,0.1]` 的 Softmax 约为 `[0.659,0.242,0.099]`。

为避免 `exp` 溢出，先逐行减去最大 logits：

$$
\frac{e^{z_j-c}}{\sum_ke^{z_k-c}}=\frac{e^{z_j}}{\sum_ke^{z_k}}
$$

其中 $c=\max_kz_k$。这不会改变 Softmax 概率。

```python
shifted_scores = z2 - np.max(z2, axis=1, keepdims=True)
exp_scores = np.exp(shifted_scores)
probs = exp_scores / np.sum(exp_scores, axis=1, keepdims=True)
```

- `axis=1`：按行处理每个样本的 3 个类别。
- `keepdims=True`：让最大值或求和结果保留形状 `(N,1)`，便于广播到 `(N,3)`。
- `probs` 的形状仍为 `(N,3)`，且 `np.sum(probs, axis=1)` 应当接近全 1。

## 3. 交叉熵与 L2 正则化

### 3.1 单样本交叉熵

真实标签的 one-hot 形式为 $y_j\in\{0,1\}$。交叉熵：

$$
L_i=-\sum_{j=0}^{C-1}y_{ij}\log p_{ij}
$$

因为 one-hot 只有真实类别 $y_i$ 对应的分量为 1，所以：

$$
\boxed{L_i=-\log p_{i,y_i}}
$$

如真实类别为 1，预测概率为 `[0.2,0.6,0.2]`，则单样本损失 $-\log 0.6\approx0.511$。

正确类别概率越接近 1，损失越接近 0；正确类别概率接近 0，损失变大。

### 3.2 Batch 平均损失

$$
\boxed{L_{\mathrm{data}}=-\frac1N\sum_{i=1}^N\log p_{i,y_i}}
$$

```python
correct_probs = probs[np.arange(N), y]
data_loss = -np.mean(np.log(correct_probs))
```

这里 `np.arange(N)` 产生行索引，`y` 产生相应的正确类别列索引。例如 `y=[2,0,1]` 时依次取 `probs[0,2]`、`probs[1,0]`、`probs[2,1]`。

**数值稳定性说明**：直接 `np.log(correct_probs)` 在概率下溢为 0 时会遇到 `log(0)`。之前讨论的 `np.log(correct_probs + 1e-12)` 可避免直接取零对数，但会略微改变严格损失的导数。更稳定且与后面标准梯度公式一致的交叉熵实现是：

```python
log_sum_exp = np.log(np.sum(exp_scores, axis=1))
data_loss = -np.mean(shifted_scores[np.arange(N), y] - log_sum_exp)
```

这里利用了 $-\log p_{y}=-(s_y-\log\sum_ke^{s_k})$，其中 $s$ 为逐行平移后的 logits。进行数值梯度检查时优先使用这个写法。

### 3.3 L2 正则化

$$
\boxed{L_{\mathrm{reg}}=\frac{\lambda}{2}\left(\|W_1\|_F^2+\|W_2\|_F^2\right)}
$$

其中 $\|W\|_F^2=\sum_{i,j}W_{ij}^2$，$\lambda$ 对应代码参数 `reg`。

```python
reg_loss = 0.5 * reg * (np.sum(W1**2) + np.sum(W2**2))
loss = data_loss + reg_loss
```

本作业只正则化 `W1` 和 `W2`，不正则化偏置。`0.5` 是原始题目要求，且使梯度公式简洁：

$$
\frac{\partial}{\partial W}\left(\frac{\lambda}{2}\|W\|_F^2\right)=\lambda W
$$

总损失：

$$
\boxed{L=L_{\mathrm{data}}+L_{\mathrm{reg}}}
$$

## 4. 反向传播的基本思想：链式法则

前向传播：

$$
X\longrightarrow Z_1\longrightarrow H_1\longrightarrow Z_2\longrightarrow P\longrightarrow L
$$

反向传播沿相反方向求梯度。单变量链式法则：

$$
\boxed{\frac{\partial L}{\partial w}=\frac{\partial L}{\partial z}\frac{\partial z}{\partial w}}
$$

对于一个变量通过**多条路径**影响损失的情况，需要将每条路径的梯度贡献求和。例如 $h$ 同时影响 $z_1$、$z_2$：

$$
\frac{\partial L}{\partial h}=\frac{\partial L}{\partial z_1}\frac{\partial z_1}{\partial h}+\frac{\partial L}{\partial z_2}\frac{\partial z_2}{\partial h}
$$

反向传播既要计算当前层的**参数梯度**，也要计算对当前层**输入的梯度**，以便继续向前一层传递。

## 5. 输出层起点：Softmax + 交叉熵求导

### 5.1 对一个样本进行推导

设真实类别索引为 $t$：

$$
p_t=\frac{e^{z_t}}{\sum_ke^{z_k}}
$$

$$
L_i=-\log p_t=-z_t+\log\sum_ke^{z_k}
$$

对第 $j$ 个 logit 求导：

$$
\frac{\partial L_i}{\partial z_j}
=-\mathbf1(j=t)+\frac{e^{z_j}}{\sum_ke^{z_k}}
=p_j-y_j
$$

其中 $\mathbf1(j=t)$ 在 $j$ 为真实类别时取 1，否则取 0。因此：

$$
\boxed{\frac{\partial L_i}{\partial z}=p-y}
$$

例如真实类别为 1，预测 $p=[0.2,0.6,0.2]$，one-hot $y=[0,1,0]$，则梯度为 `[0.2,-0.4,0.2]`。

- 错误类别的梯度通常为正，梯度下降倾向于降低对应 logits。
- 正确类别梯度为 $p_t-1$，通常为负，梯度下降倾向于提高正确类别 logit。

### 5.2 推广到 batch

因为使用平均交叉熵，所以每个样本的贡献还要除以 $N$：

$$
\boxed{dZ_2=\frac{\partial L_{\mathrm{data}}}{\partial Z_2}=\frac{P-Y}{N}}
$$

形状为 $(N,3)$。`Y` 不必显式构造，只需对真实类别列的位置减 1：

```python
dz2 = probs.copy()
dz2[np.arange(N), y] -= 1
dz2 /= N
```

- `.copy()` 避免后面的原地修改影响 `probs`。
- `dz2` **已除以 N**，后面计算 `dW2` 和 `dW1` 时不要重复除以 N。
- L2 正则化只直接依赖权重，不改变此处的 `dz2` 公式。
- 每个样本的 `dz2` 行元素之和约为 0，因为 $\sum_j(p_j-y_j)=0$。

## 6. 第二层参数梯度：dW2、db2

前向公式：

$$
Z_2=H_1W_2+b_2
$$

对第 $i$ 个样本、第 $j$ 个输出神经元：

$$
z_{2,ij}=\sum_{k=1}^{10}h_{ik}w_{2,kj}+b_{2,j}
$$

### 6.1 dW2：链式法则与矩阵转置

对某个权重 $w_{2,kj}$，有：

$$
\frac{\partial L_{\mathrm{data}}}{\partial w_{2,kj}}=\sum_{i=1}^Nh_{ik}\,dz_{2,ij}
$$

将同一隐藏特征与相应输出梯度按样本维度相乘并求和，恰好就是矩阵乘法：

$$
\underbrace{H_1^T}_{(10,N)}\underbrace{dZ_2}_{(N,3)}=\underbrace{dW_{2,\mathrm{data}}}_{(10,3)}
$$

再加 L2 正则项：

$$
\boxed{dW_2=H_1^TdZ_2+\lambda W_2}
$$

```python
dW2 = np.dot(h1.T, dz2) + reg * W2
```

**为什么转置？** `h1.T` 把隐藏神经元维度放到行、样本维度放到列，从而对每个参数沿样本维度正确累加贡献；不只是为了“凑维度”。

### 6.2 db2：沿样本维度求和

偏置在一个 batch 的所有样本中共享，且 $\partial z_{2,ij}/\partial b_{2,j}=1$：

$$
\boxed{db_{2,j}=\sum_{i=1}^{N}dz_{2,ij}}
$$

```python
db2 = np.sum(dz2, axis=0)
```

`axis=0` 对所有样本求和，结果形状 `(3,)`，与 `b2` 一致；偏置没有 L2 正则项。

## 7. 将梯度从第二层传回隐藏层：dh1

第二层权重梯度计算完后，第一层仍然需要收到来自后续网络的梯度。

对同一样本的第 $k$ 个隐藏神经元，考虑它通往所有三个输出神经元的路径：

$$
\frac{\partial L}{\partial h_{ik}}
=\sum_{j=1}^{3}\frac{\partial L}{\partial z_{2,ij}}\frac{\partial z_{2,ij}}{\partial h_{ik}}
=\sum_{j=1}^{3}dz_{2,ij}w_{2,kj}
$$

因此矩阵形式为：

$$
\boxed{dH_1=dZ_2W_2^T}
$$

维度：

$$
(N,3)(3,10)=(N,10)
$$

```python
dh1 = np.dot(dz2, W2.T)
```

**容易混淆**：这里是 `W2.T`，**不是** `dW2.T`。求输入梯度需要的是前向传播用的权重，而不是权重本身的梯度。这里没有再加 `reg * W2`：L2 对 `W2` 的作用已经计入 `dW2`，与 `h1` 的求导无关。

## 8. 通过 ReLU：dz1

因为：

$$
H_1=\operatorname{ReLU}(Z_1)
$$

ReLU 的导数是：

$$
\operatorname{ReLU}'(z)=
\begin{cases}
1,&z>0\\
0,&z<0
\end{cases}
$$

在 $z=0$ 处数学上不可导；本作业采用导数为 0 的常见实现约定。

对每个元素应用链式法则：

$$
\boxed{dZ_1=dH_1\odot\mathbf1(Z_1>0)}
$$

$\odot$ 表示**逐元素乘法**。

```python
dz1 = dh1 * (z1 > 0)
```

例如：

- `z1 = [-2, 3, 0.5, -1]`
- `dh1 = [0.1, -0.4, 0.2, 0.5]`
- ReLU 导数掩码：`[0, 1, 1, 0]`
- `dz1 = [0, -0.4, 0.2, 0]`

负半轴的梯度被截断，正半轴保持原样。与前面矩阵乘法不同，这里要使用 `*`，而非 `np.dot()`。

## 9. 第一层参数梯度：dW1、db1

第一层的前向公式为：

$$
Z_1=XW_1+b_1
$$

### 9.1 dW1

第 $i$ 个样本、第 $j$ 个隐藏神经元：

$$
z_{1,ij}=\sum_{k=1}^{4}x_{ik}w_{1,kj}+b_{1,j}
$$

对权重 $w_{1,kj}$：

$$
\frac{\partial L_{\mathrm{data}}}{\partial w_{1,kj}}=\sum_{i=1}^{N}x_{ik}\,dz_{1,ij}
$$

矩阵形式并加上 L2 项：

$$
\boxed{dW_1=X^TdZ_1+\lambda W_1}
$$

维度：

$$
(4,N)(N,10)=(4,10)
$$

```python
dW1 = np.dot(X.T, dz1) + reg * W1
```

这与第二层的 `dW2 = h1.T @ dz2 + reg*W2` 是相同的全连接层求导模式，只是输入由 `h1` 换成了 `X`。

### 9.2 db1

$$
\boxed{db_{1,j}=\sum_{i=1}^{N}dz_{1,ij}}
$$

```python
db1 = np.sum(dz1, axis=0)
```

形状 `(10,)`，与 `b1` 一致，也不加 L2 正则项。

## 10. 完整反向传播代码

放在 `compute_neural_net_loss()` 的第二个 TODO 中：

```python
# Softmax + 交叉熵对 logits 的梯度
dz2 = probs.copy()
dz2[np.arange(N), y] -= 1
dz2 /= N

# 第二层参数梯度
dW2 = np.dot(h1.T, dz2) + reg * W2
db2 = np.sum(dz2, axis=0)

# 继续反向传到隐藏层
dh1 = np.dot(dz2, W2.T)

# ReLU 的反向传播
dz1 = dh1 * (z1 > 0)

# 第一层参数梯度
dW1 = np.dot(X.T, dz1) + reg * W1
db1 = np.sum(dz1, axis=0)

# 保存梯度
grads['W1'] = dW1
grads['W2'] = dW2
grads['b1'] = db1
grads['b2'] = db2
```

### 梯度形状速查

| 梯度 | 计算式 | 形状 |
|---|---|---|
| `dz2` | `(P-Y)/N` | `(N,3)` |
| `dW2` | `h1.T @ dz2 + reg*W2` | `(10,3)` |
| `db2` | `sum(dz2, axis=0)` | `(3,)` |
| `dh1` | `dz2 @ W2.T` | `(N,10)` |
| `dz1` | `dh1 * (z1 > 0)` | `(N,10)` |
| `dW1` | `X.T @ dz1 + reg*W1` | `(4,10)` |
| `db1` | `sum(dz1, axis=0)` | `(10,)` |

## 11. SGD 如何使用梯度更新参数

算出所有梯度后，训练循环用 SGD 更新每个参数：

$$
\boxed{\theta\leftarrow\theta-\eta\,\frac{\partial L}{\partial\theta}}
$$

其中 $\eta$ 是学习率、$\theta\in\{W_1,b_1,W_2,b_2\}$。

```python
def sgd_update(params, grads, learning_rate):
    for key in params:
        params[key] += -learning_rate * grads[key]
```

- 梯度为正时，参数沿负方向更新。
- 梯度为负时，参数沿正方向更新。
- mini-batch SGD 使用当前批次的数据估计梯度，训练准确率、loss 不必逐轮单调变化。

## 13. 一页公式总览（复习重点）

### 前向传播

$$
\begin{aligned}
Z_1&=XW_1+b_1\\
H_1&=\operatorname{ReLU}(Z_1)\\
Z_2&=H_1W_2+b_2\\
P_{ij}&=\frac{e^{Z_{2,ij}}}{\sum_ke^{Z_{2,ik}}}\\
L_{\mathrm{data}}&=-\frac1N\sum_i\log P_{i,y_i}\\
L_{\mathrm{reg}}&=\frac\lambda2(\|W_1\|_F^2+\|W_2\|_F^2)\\
L&=L_{\mathrm{data}}+L_{\mathrm{reg}}
\end{aligned}
$$

### 反向传播

$$
\boxed{
\begin{aligned}
dZ_2&=\frac{P-Y}{N}\\
dW_2&=H_1^TdZ_2+\lambda W_2\\
db_2&=\sum_{i=1}^{N}dZ_{2,i}\\
dH_1&=dZ_2W_2^T\\
dZ_1&=dH_1\odot\mathbf1(Z_1>0)\\
dW_1&=X^TdZ_1+\lambda W_1\\
db_1&=\sum_{i=1}^{N}dZ_{1,i}
\end{aligned}
}
$$

> **记忆方式**：对任意全连接层 $Z=AW+b$，收到上游梯度 $dZ$ 后，参数梯度为 $dW=A^TdZ$、$db=\sum_i dZ_i$；传给上一层的梯度为 $dA=dZW^T$。如果该层权重有本作业形式的 L2 正则化，再把 $\lambda W$ 加到 `dW`。经过 ReLU 时，逐元素乘以激活前输入是否大于 0 的掩码。
